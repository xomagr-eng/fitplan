# FitPlan — Διατροφή & Γυμναστική 🏋️

Δωρεάν, **offline** web εφαρμογή για αυτόματα προγράμματα **διατροφής, δίαιτας & γυμναστικής**.

👉 **Άνοιξέ την:** https://xomagr-eng.github.io/fitplan/

## Τι κάνει
- Υπολογισμός BMR / TDEE / θερμίδων στόχου / μακροθρεπτικών (Mifflin-St Jeor & Katch-McArdle)
- Στόχος βάρους με χρονοδιάγραμμα, μετρήσεις μεζούρας (λίπος σώματος U.S. Navy, WHtR)
- 7ήμερο πρόγραμμα διατροφής + πρόγραμμα γυμναστικής (Full Body / Upper-Lower / PPL)
- Παρακολούθηση προόδου με γραφήματα
- Λίστα αγορών (ποσότητες, ×άτομα, .txt / εικόνα με QR / εκτύπωση)
- Πολλαπλά προφίλ (μέλη οικογένειας) + σύγκριση
- Αλλαγή χρώματος, φωτεινό/σκοτεινό θέμα, **PWA** (εγκατάσταση σαν εφαρμογή, πλήρης οθόνη)

## Ιδιωτικότητα
Όλα τα δεδομένα μένουν **τοπικά στη συσκευή σου** (localStorage). Τίποτα δεν στέλνεται σε server.

## Εγκατάσταση στο κινητό
Άνοιξε το link → μενού browser → **«Προσθήκη στην αρχική οθόνη»**. Ανοίγει σαν κανονική εφαρμογή, με δικό της εικονίδιο και offline.

*Δεν υποκαθιστά ιατρό/διαιτολόγο. Συμβουλέψου ειδικό πριν ξεκινήσεις δίαιτα ή πρόγραμμα άσκησης.*
